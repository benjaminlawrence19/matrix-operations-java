# Matrix Operations and Linear Algebra in Java

A Java application developed to implement matrix operations and complex number functionality, applying object-oriented programming principles.

## Overview

The project explores computational aspects of linear algebra through a Java implementation, using four classes to organise matrix and complex number operations.

## Features

- Matrix operations and manipulation.
- Complex number representation and calculations.
- LU decomposition.
- Calculation of matrix determinants using LU decomposition.
- Object-oriented design using multiple Java classes.

## Technologies

- Java
- Object-Oriented Programming
- Linear Algebra

## Concepts Demonstrated

- Matrix operations
- Complex numbers
- LU decomposition
- Determinants
- Object-oriented programming
